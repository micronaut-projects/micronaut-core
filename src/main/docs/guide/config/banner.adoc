Since Micronaut framework 2.3 a banner is shown when the application starts. It is enabled by default, and it also shows the Micronaut version.

[source,shell,subs="attributes"]
----
$ ./gradlew run
 __  __ _                                  _
|  \/  (_) ___ _ __ ___  _ __   __ _ _   _| |_
| |\/| | |/ __| '__/ _ \| '_ \ / _` | | | | __|
| |  | | | (__| | | (_) | | | | (_| | |_| | |_
|_|  |_|_|\___|_|  \___/|_| |_|\__,_|\__,_|\__|
  Micronaut ({version})

17:07:22.997 [main] INFO  io.micronaut.runtime.Micronaut - Startup completed in 611ms. Server Running: http://localhost:8080
----

To customize the text banner, create the file `src/main/resources/micronaut-banner.txt` and it will be used instead.

When the application starts in a Kitty, iTerm2, or WezTerm terminal, the default banner displays the Micronaut logo. You can also replace this image.

Set the `MICRONAUT_BANNER_MODE` environment variable to choose the output mode. The default, `auto`, detects the terminal protocol. Set it to `ascii` to always print ASCII art, or to `kitty` to force the Kitty graphics protocol (which is supported by iTerm2 as well). A forced protocol bypasses terminal detection, so use it only when the output terminal supports it. If the image resource is missing, Micronaut prints the ASCII banner.

Set `MICRONAUT_BANNER_THEME` to `light` or `dark` to select the right logo for the given terminal theme. The default, `auto`, checks the `COLORFGBG` environment variable when it is set: background color index `7` or `15` selects a logo for light mode terminals; other values and an unset variable select dark mode. Set the variable explicitly when the terminal does not provide `COLORFGBG`.

[source,bash]
----
MICRONAUT_BANNER_MODE=ascii ./gradlew run
MICRONAUT_BANNER_MODE=kitty ./gradlew run
MICRONAUT_BANNER_MODE=kitty MICRONAUT_BANNER_THEME=light ./gradlew run
----

To display your own image in these terminals, add a PNG at the following location. It is displayed at its pixel size and is included in GraalVM native images automatically:

[source,text]
----
src/main/resources/META-INF/micronaut/banner.png
----

To use a different image in terminals with a light background, also add `src/main/resources/META-INF/micronaut/banner-light.png`.

In these terminals `banner.png` is used in preference to `micronaut-banner.txt`, so you can provide both and the text banner is printed everywhere else.

You can provide an SVG image instead, at `src/main/resources/META-INF/micronaut/banner.svg` (and `banner-light.svg` for a light background). It is used in preference to `banner.png`, is rendered at its `width` and `height` in pixels, and can be animated with SMIL `<animate>` and `<animateTransform>` elements, which play once, or in a loop when an animation has `repeatCount="indefinite"`. The default Micronaut logo is such an animated SVG. Use `currentColor` to follow the terminal theme: it is white on a dark background and black on a light one.

[source,xml]
----
<svg width="300" height="60" xmlns="http://www.w3.org/2000/svg">
  <circle cx="30" cy="30" r="20" fill="currentColor">
    <animate attributeName="opacity" values="0;1" dur="0.5s" fill="freeze"/>
    <animateTransform attributeName="transform" type="translate" values="-30 0;0 0" dur="0.5s"
                      calcMode="spline" keySplines="0.2 0.8 0.2 1" fill="freeze"/>
  </circle>
</svg>
----

The banner renderer supports a subset of SVG: the `path` (with every command), `polygon`, `polyline`, `rect`, `circle`, `ellipse` and `g` elements, transforms, and the `fill`, `fill-opacity`, `fill-rule`, `opacity` and `color` properties. Strokes, text, gradients, and clipping are not rendered, so convert text and strokes to paths. A terminal that displays images but not animations shows the image as it is when the animation ends.

To disable it, modify your `Application` class:

[source,java]
----
public class Application {

    public static void main(String[] args) {
        Micronaut.build(args)
                 .banner(false) // <1>
                 .start();
    }
}
----
<1> Disable the banner

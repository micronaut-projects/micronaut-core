The `micronaut-dev` module runs an application so that a change to its sources takes effect without restarting the JVM. A launcher, api:dev.MicronautDevMain[], loads the application's classes and resources through a reloadable class loader, watches the source and resource directories, recompiles what changed with the JDK compiler, and restarts the application context on a new generation of that loader while the JVM, the compiler's warm state and the singletons a api:context.reload.BeanRetentionPolicy[] retains, such as a connection pool, survive.

The module is experimental. The build plugins for Gradle and Maven start it for you; the sections below describe what happens underneath so that you can configure it, retain your own beans, and write beans that follow a reload.

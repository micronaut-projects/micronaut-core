The build tools can restart the whole application, in a new JVM, whenever a source file changes. Each restart starts from a clean state, and pays for the startup of the JVM and of the application. <<devMode, Development mode>> keeps the JVM running instead.

=== Gradle Restart

Gradle automatic restart can be activated when using the Micronaut Gradle plugin by activating Gradle's support for https://docs.gradle.org/current/userguide/command_line_interface.html#sec:continuous_build[continuous builds] via the `-t` flag:

.Using Gradle for Automatic Restart
[source,bash]
----
./gradlew run -t
----

Every time you make a change to class or resources, Gradle recompiles and restarts the application.

=== Maven Restart

The `mn:run` goal of the Micronaut Maven plugin recompiles through Maven and restarts the application every time you change a class:

.Using the Micronaut Maven Plugin
[source,bash]
----
$ ./mvnw mn:run
----

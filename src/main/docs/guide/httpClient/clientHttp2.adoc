By default, Micronaut's HTTP client is configured to support HTTP 1.1. To enable support for HTTP/2, set the supported HTTP version in configuration:

.Enabling HTTP/2 in Clients
[configuration]
----
micronaut:
  http:
    client:
      http-version: 2.0
----

Or by specifying the HTTP version to use when injecting the client:

.Injecting an HTTP/2 Client
[source,java]
----
@Inject
@Client(httpVersion=HttpVersion.HTTP_2_0)
ReactorHttpClient client;
----

Over HTTP/2 the server may only send as many response body bytes as the flow-control window the
client advertises, until the client acknowledges them. `micronaut.http.client.http2.initial-window-size`
sets that window per stream (1 MiB by default); the window of the connection as a whole follows it.
A larger window keeps high-latency downloads going at the speed of the network, at the cost of
buffering more unread response data per connection.

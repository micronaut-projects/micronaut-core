https://www.scala-lang.org[Scala] support in Micronaut is implemented for Scala 3.

Scala 2.x is not supported by this language adapter.

== How Scala Support Works

Micronaut processes Scala source with `micronaut-inject-scala`, a Scala 3 compiler plugin. The plugin is a standard Scala compiler plugin that runs after type checking and before pickling. It reads typed compiler trees and compiler symbols, adapts them to Micronaut's Element API, and then reuses the same visitor, annotation metadata, bean-definition, AOP, and introspection infrastructure used by the other language adapters.

The Scala adapter models classes, traits, methods, fields, properties, constructors, parameters, enums, generic placeholders, wildcard bounds, and package elements through Scala-specific Element API wrappers. Annotation metadata is built from compiler symbols and annotation trees, including annotation stereotypes, parent annotations, aliases, defaults, repeatable annotations, retention, targets, class literals, enum constants, arrays, and type-use nullability where the Scala compiler exposes that information.

The adapter should favor compiler symbols and typed trees over reflection or class loading. Runtime class loading is not part of the Scala source model.

== Additional Scala Notes

Use Scala traits for interfaces and introduction advice contracts. Micronaut resolves inherited generic method metadata through source-defined trait type arguments.

Scala `val` constructor parameters model read-only bean properties. Scala `var` members model writable properties and generate setters. Prefer constructor parameters for dependency injection and immutable state.

Scala companion objects and synthetic compiler artifacts are filtered from the source model unless they represent a usable element such as a companion-defined nested bean.

Importing already compiled Scala library beans with bean import remains unsupported in the initial Scala adapter. Define Scala beans in source compiled with the Micronaut Scala compiler plugin. Scala 3.3.8 is the initial compiler target for this adapter and its compiler plugin artifact.
The full Scala compiler version remains part of the compiler-plugin artifact name.

Async Python code can also await Java async values returned by injected services and clients. `CompletionStage<T>` awaits to `T`. Reactive `Publisher<T>` and Reactor `Mono<T>` values are treated as scalar awaitables:

snippet::micronaut.docs.asyncio.AsyncBackendController[tags="publisherBackend", indent=0, title="Publisher backend"]

snippet::micronaut.docs.asyncio.BackendClient[tags="publisherClient", indent=0, title="Publisher client"]

snippet::micronaut.docs.asyncio.AsyncDemoController[tags="awaitPublisher", indent=0, title="Awaiting a scalar Publisher"]

For a `Publisher`, Micronaut requests one item, completes the await with the first item, and cancels the subscription. If the publisher completes empty, the awaited value is `None`; if it signals an error, the await fails. Multi-item `Flux` values are not collected into a list implicitly. Use reactive operators such as `collectList()` when all emitted items are required.

snippet::micronaut.docs.asyncio.AsyncDemoController[tags="taskGroup", indent=0, title="TaskGroup on the Micronaut event loop"]

Asyncio bridge support is enabled by default. Disable it with:

[configuration]
----
micronaut:
  python:
    asyncio:
      enabled: false
----

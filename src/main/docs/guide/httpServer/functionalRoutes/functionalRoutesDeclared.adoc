A api:web.router.builder.RouteDeclaration[] is the shape of a route, an HTTP method and a URI template, declared apart from its handler:

snippet::io.micronaut.docs.server.functional.AuditedRoutes[tags="declaration", indent=0, title="A route declaration"]

snippet::io.micronaut.docs.server.functional.AuditedRoutes[tags="declared", indent=0, title="A handler bound to the declaration"]

<1> `RouteDeclaration.of(method, uriTemplate)` declares a route in code.
<2> `handle(declaration, handler)`, and the `handleAsync` and `handleForm` variants, bind a handler to it. The route behaves like one declared with `GET(...)`, including its implicit `HEAD` route.

A declared route is registered with the index keys of its declaration, and built the first time the router uses it. Declarations are meant to be generated at compile time, e.g. as the constants of an enum generated by an annotation processor from the web annotations of a framework, together with a matcher that finds the declaration of a request path in generated code: see the SPI in the package pkg:web.router.spi[]. A declaration cannot be bound in a group with a prefix, whose URIs its keys do not describe.

Functional routes are experimental. Keep these limitations in mind:

* Routes and their settings are fixed when the router is created. Configure them inside `HttpRoutes.routes(...)` and group callbacks; do not retain builders to make runtime changes.
* Tools that discover routes from controller annotations, such as Micronaut OpenAPI, do not discover handler routes.
* There is no Kotlin DSL or support for `suspend` handler functions. The streaming APIs do provide <<functionalRoutesStreaming, coroutine helpers>>.

=== Validation

Handler bodies and path variables are not automatically validated. To validate them, call a bean method whose parameters carry constraints such as `@Valid` or `@NotBlank`. A constraint violation produces `400`, as it does for a controller.
